# ContactHub - Smart Contact Manager

A contact manager built with vanilla JavaScript. Contacts are stored in the browser with localStorage, so the list survives reloads without any backend.

## Features

- Add, edit, and delete contacts, with a confirmation step before deleting
- Edit flow through a dedicated modal
- Avatar initials generated from contact names
- HTML escaping on all user input to keep the UI safe from injected markup
- Persistent storage with localStorage

## Tech stack

- Vanilla JavaScript
- HTML5, CSS3

## Getting started

Open `index.html` in a browser - no build step needed.
